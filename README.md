# MAVUENI-HOTEL-ENTERPRISE-NETWORKING-PROJECT
Designed and configured an enterprise network with two core routers, two Layer 3 switches, six access switches, and two ISPs. Implemented VLANs, SSH, subnetting, OSPF, inter-VLAN routing, DHCP, wireless connectivity, switchport security, PAT, ACLs, default static routing, and network connectivity testing.
